# Élan Scents

A premium Gulf fragrance marketplace built with Next.js and TypeScript.

## Project goals
- Luxury storefront for premium perfumes
- Marketplace architecture with multiple stores and brands
- Modern responsive design
- Short-term storefront demo and long-term marketplace foundation

## Stack
- Next.js 14
- TypeScript
- Tailwind CSS-ready structure
- Responsive custom styling

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run start
```

## Notes
This repo is the base storefront and admin structure for the Élan Scents project. It is intended to evolve into a complete marketplace with product sourcing, commissions, storefront management, and store integration.
